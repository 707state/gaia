## 2. Userspace Runtime Replace Demo: replace `/home/jask/lua` `luaB_print()`

### What this demo does

This demo targets a running `/home/jask/lua` process and replaces the userspace function `luaB_print()` at runtime. The mechanism is:

1. Resolve the original function address in the target process.
2. Inject a replacement `.so` into the process with `ptrace` + `__libc_dlopen_mode`.
3. Resolve the replacement symbol address from the injected `.so`.
4. Overwrite the original function entry with a trampoline jump.

The eBPF uprobes are used here for monitoring and auditing, not for doing the actual replacement.

## Quick distinction between the two demos

- Kernel livepatch demo:
  - scope: kernel function replacement
  - target: `cmdline_proc_show`
  - effect surface: `/proc/cmdline`
  - mechanism: `klp_patch` kernel module, `insmod`, sysfs enable

- `/home/jask/lua` demo:
  - scope: userspace function replacement
  - target: running process `/home/jask/lua`, symbol `luaB_print`
  - effect surface: future calls to that userspace function
  - mechanism: `ptrace` attach, remote `dlopen`, resolve replacement symbol, overwrite function entry with trampoline
